# Negative Grid API

## Overview
A secure, multi-threaded telemetry processing and rendering engine server pipeline designed for trace-dye monitoring, hopping-agent dispatch, and 3D node-origin spatial mapping.

## Architecture & Components
* **`prism_window_monitor.py`**: Monitors viewport states and triggers hopping agents upon anomaly detection.
* **`hopping_agent_transmitter.py`**: Dispatches split-intelligence telemetry payloads across dynamic side-attached endpoints.
* **`crypto_tokenization.py`**: Encrypts and tokenizes data streams for secure transport.
* **`sentinel_orchestrator.py`**: Manages execution state and coordinates automated feedback loops.
* **`Prism-Stream-Processor.sh`**: Unix stream processing utility using `cat`, `sed`, and `awk` to parse socket mappings and system logs.

## Repository Structure
- `core/telemetry/`: Core telemetry and agent scripts.
- `core/server/`: Processing pipelines and thermal management watchdogs.
